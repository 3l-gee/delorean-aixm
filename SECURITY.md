## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it privately rather than creating a public issue.

## How to Submit

* Send details of the vulnerability to delorean.aixm@gmail.com or create a GitHub Security Advisory.
  * Include a Description of the issue and potential impact
  * Step-by-step instructions or proof-of-concept (PoC) to reproduce it
  * Affected versions or components
  * Any suggested fixes or mitigations

## Response & Handling Timeline

1. **Acknowledgement:** You will receive an initial response within **48 hours** confirming receipt of your report.
2. **Assessment:** We will investigate and confirm the report within **7 days**.
3. **Resolution:** If validated, a fix will be prepared, tested, and released as a patch as soon as possible.
4. **Disclosure:** Once resolved, a security advisory will be published acknowledging your contribution (if desired).
5. **Hard Cap:** If no resolution or mutual agreement is reached, public disclosure or coordinated release will occur no later than **90 days** from the initial report date.

## Security Best Practices

Do not submit pull requests containing private credentials, API keys, or sensitive environment configurations.
